# EventPulse Frontend

Frontend web application for EventPulse event booking platform built with React, TypeScript, Vite, Tailwind CSS, TanStack Router, and TanStack Query.

## Features

- Service discovery & interactive map search
- Event booking workflows
- Provider listing management
- Admin management dashboard
- Dark mode theme by default

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
